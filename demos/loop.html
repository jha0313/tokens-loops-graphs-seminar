## Iteration (one per turn)

0. First turn only: `bash .loop/e2e-speed/check.sh` before any edit (starts the clock, checks the environment).
1. Read `LOOP.md`, `state.md`, `tail -5 .loop/e2e-speed/results.tsv`.
2. Take the top idea in "Next ideas". Read the code. Make ONE change (one idea, smallest diff).
3. Optional, 5 s: `E2E_MODE=fixture N=1 bash scripts/e2e-gen/measure.sh smoke` must show `"all_completed": true`.
   Its sha is NOT the guard (fixture mode has no latency, so calls interleave differently: `73243b6d…`).
4. `bash .loop/e2e-speed/measure.sh candidate "<one line: what changed>"` (foreground, timeout 600000).
5. `verdict=keep` → `bash .loop/e2e-speed/snapshot.sh save`. `verdict=reject` → `bash .loop/e2e-speed/snapshot.sh restore`.
   Exit 2 (not measured) → no row; go to step 6 and act on its last line.
6. `bash .loop/e2e-speed/check.sh`. Put its full stdout in a fenced block.
7. Update `state.md`: the idea → kept or rejected, the numbers, the reason; next ideas; the last check output.

## Assumptions (non-interactive run; nobody could answer)

1. "Output unchanged" = the replay `output_sha256` above AND the same model calls. Skipping, deduplicating or
   caching a call is out even when the sha stays: it changes production behaviour and cost.
2. A change must be equivalent on every path, not only this fixture's (e.g. a judge may not start before a gate
   that can still repair its input image). No speculative call that a later step may throw away.
3. Concurrency caps, retry counts, re-ask counts, timeouts, backoff and poll intervals count as thresholds: unchanged.
   Replay has no rate limits, so a gain there would not hold in production. If one is on the critical path,
   write it in state.md "For a human".
4. A gate's decision rule and its commit order (e.g. the sibling headline gate claims in fan-out order) are part of
   the gate. Call sites may start independent work earlier or stop awaiting what a step does not read.
5. The workspace is this clone (no remote, outside the user's main checkout), so no extra worktree. Without commits,
   the kept state is `accepted.patch`; `snapshot.sh restore` puts the tree back to HEAD + that patch.
6. The repo's work-claim (`npm run work:claim`, GitHub) and changelog-fragment rules need network or a PR; this loop
   has neither. They apply when a human turns `accepted.patch` into a PR.
7. The tsc guard runs with `NODE_OPTIONS=--max-old-space-size=4096` (the repo's form of the same command).
8. Code rules still apply to the change: ≤ 300 lines per file, no `any`, match the surrounding style, and update
   `services/thumbnail-generator/CLAUDE.md` or `docs/headlines.md` if the change makes a sentence there wrong.

# Existing tests never change or go away (a new test file is fine).

# Read only when a command failed: these mean the machine, not the change.
ENV_ERR='ENOSPC|no space left on device|EACCES|EPERM|EMFILE|ENOMEM|heap out of memory|command not found'

untracked() { git -C "$WS" ls-files --others --exclude-standard "${PATHSPEC[@]}"; }

# The change vs HEAD as one patch, new files included.
change_diff() {
  git -C "$WS" diff --binary --no-renames HEAD "${PATHSPEC[@]}"
  untracked | while IFS= read -r f; do (cd "$WS" && git diff --binary --no-index /dev/null "$f") || true; done
}

tree_hash() {
  local d
  d=$(change_diff)
  if [ -z "$d" ]; then echo clean; else printf '%s' "$d" | shasum -a 256 | cut -c1-12; fi
}

# Prints "<status> <path>" for every protected path the change touches; prints nothing when clean.
protected_violations() {
  { git -C "$WS" diff --name-status --no-renames HEAD "${PATHSPEC[@]}"; untracked | sed 's/^/A	/'; } |
    while IFS=$'\t' read -r st f; do
      if printf '%s\n' "$f" | grep -Eq "$PROTECTED"; then echo "$st $f"
      elif [ "$st" != A ] && printf '%s\n' "$f" | grep -Eq "$TESTS"; then echo "$st $f (existing test)"
      fi
    done
}

# The user's guards. $1 = log. Returns 0 pass, 1 the change failed them, 2 environment error. Sets GUARD.
run_guards() {
  local log=$1 rc
  GUARD="tsc -p tsconfig.pipeline.json"
  (cd "$WS" && NODE_OPTIONS=--max-old-space-size=4096 npx tsc -p tsconfig.pipeline.json --noEmit) >"$log" 2>&1

    (cd "$WS" && npx vitest run services/thumbnail-generator pipeline-server) >>"$log" 2>&1
    rc=$?
  fi
  [ "$rc" -eq 0 ] && return 0
  grep -Eq "$ENV_ERR" "$log" && return 2
  return 1
}

snapshot.sh (commit 없이 채택된 변경을 accepted.patch로 저장·복원)

#!/usr/bin/env bash
# The accepted state without commits (the loop never commits): HEAD + accepted.patch.
#   save     after verdict=keep: store the current change as accepted.patch
#   restore  after verdict=reject: put the tree back to HEAD + accepted.patch
#   hash     print the current tree hash (the "tree" column of results.tsv)
set -euo pipefail
. "$(cd "$(dirname "$0")" && pwd)/lib.sh"
cd "$WS"

case "${1:-}" in
  hash) tree_hash ;;
  save)
    cur=$(tree_hash)
    kept=$(awk -F'\t' '$3=="keep"' "$TSV" | tail -1 | cut -f7)
    [ "$cur" = "$kept" ] || { echo "refused: tree $cur is not the last kept tree (${kept:-none})" >&2; exit 1; }
    change_diff >"$LOOP_DIR/accepted.patch"
    echo "$cur" >"$LOOP_DIR/accepted.tree"
    echo "saved accepted.patch (tree $cur)"
    ;;
  restore)
    git diff --cached --name-only --diff-filter=A HEAD "${PATHSPEC[@]}" | while IFS= read -r f; do git rm -q --cached -- "$f"; done
    git checkout HEAD "${PATHSPEC[@]}"
    untracked | while IFS= read -r f; do echo "removing new file $f"; rm -f -- "$f"; done
    if [ -s "$LOOP_DIR/accepted.patch" ]; then git apply --binary "$LOOP_DIR/accepted.patch"; fi
    cur=$(tree_hash)
    want=$(cat "$LOOP_DIR/accepted.tree" 2>/dev/null || echo clean)
    [ "$cur" = "$want" ] || { echo "restore left tree $cur, expected $want" >&2; exit 1; }
    echo "restored the accepted tree ($cur)"
    ;;
  *) echo "usage: snapshot.sh save|restore|hash" >&2; exit 2 ;;
esac
