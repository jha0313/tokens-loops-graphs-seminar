# slides

"Long Running Agent의 시대, 사람의 역할은?" — 삼성전자 AI센터 세미나 3차 발표 deck이다(76장).

- `index.html`: 한 파일로 된 deck이다. 저장소 루트에서 `python3 -m http.server 8000`을 띄우고 `http://localhost:8000/slides/index.html`로 연다. 파일을 바로 열어도 된다.
- 넘기기: ← → 키. S는 슬라이드 목록이다.
- 공개판이라 발표 노트는 뺐다. 발표자 창(P)을 열면 노트 칸이 비어 있다.
- 숫자의 근거 표시(기록 · 실전 · 실험 · 공개 · 추정)는 화면에 그대로 있다. 데모 결과의 전체 기록은 `../demos/`에 있다.
